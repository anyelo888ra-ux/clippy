## ✨ Características

| Feature | Descripción |
|---------|-------------|
| 📎 **Personalidad de Clippy** | El asistente clásico de Office, pero educado |
| ⚡ **Carga instantánea** | Sin IA pesada, 0 MB de descarga |
| 🦊 **Multi-navegador** | Firefox, Chrome, Edge, Safari |
| 💬 **Respuestas inteligentes** | Detecta intención con regex |
| 😂 **Humor retro** | Chistes, referencias a XP, memes |
| 🎯 **Acciones rápidas** | Botones de ayuda, chiste, código |
| 📱 **Responsive** | Funciona en móvil |
| 🔒 **100% local** | Sin API keys, sin backend |

## 🎯 ¿Qué sabe hacer Clippy?

- 💬 **Conversar** sobre varios temas
- 😂 **Contar chistes** de programadores
- 💻 **Ayudar con código** (Python, JavaScript, HTML, CSS)
- 📚 **Recomendar recursos** (Chronioñ Search, Google, DuckDuckGo)
- 🎮 **Hablar de juegos** (Roblox, Minecraft, etc.)
- 🎵 **Hablar de música** (c00lradio, Discord)
- ⚠️ **Detectar errores/bugs**
- 🖥️ **Recordar Windows XP** (la época dorada)

## 🛠️ Stack Tecnológico

- **HTML5** → Estructura semántica
- **CSS3** → Glassmorphism, gradientes, animaciones
- **JavaScript Vanilla** → Sin frameworks, sin dependencias
- **GitHub Pages** → Hosting gratuito
- **DuckDNS** → Dominio custom gratuito
