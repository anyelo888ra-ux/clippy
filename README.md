## 🎯 ¿Qué sabe hacer Clippy?

- 💬 Conversar sobre varios temas
- 😂 Contar chistes de programadores
- 💻 Ayudar con código (Python, JavaScript, HTML, CSS)
- 📚 Recomendar recursos (Chronioñ Search, Google, DuckDuckGo)
- 🎮 Hablar de juegos (Roblox, Minecraft, etc.)
- 🎵 Hablar de música (c00lradio, Discord)
- ⚠️ Detectar errores/bugs
- 🖥️ Recordar Windows XP (la época dorada)

## 🚀 Cómo usar

### Opción 1: Ver la demo

Visita https://anyelo888ra-ux.github.io/clippy

### Opción 2: Clonar el repo

    git clone https://github.com/anyelo888ra-ux/clippy.git
    cd clippy

Abre index.html en tu navegador.

### Opción 3: Deploy propio

1. Fork este repo
2. Activa GitHub Pages en Settings → Pages
3. Tu versión estará online en https://tu-usuario.github.io/clippy
